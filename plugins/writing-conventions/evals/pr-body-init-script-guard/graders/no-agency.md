Judge the text for personification of inanimate things. FAIL only for a sentence you can quote in which an inanimate subject (a report, build, entry, option, version, PR, file, commit, test, setting, task, section, README, or similar) takes a verb of speech, volition, cognition, or possession: says, tells, wants, knows, decides, claims, asks, declares, documents, carries, holds, owns, names, judges, offers, or "whose" directly after such a noun. A program doing its runtime job is not personification: a function returns, a task writes a file, a build fails, a check rejects a version, a platform constrains a dependency. A sentence written around what happens, with no agent ("the version is shown in the report", "configured in the build"), passes. PASS in every other case, including when you are unsure. When failing, start with the quoted sentence.
